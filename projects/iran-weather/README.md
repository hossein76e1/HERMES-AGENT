# هواشناسی ایران 🌤

وب‌اپلیکیشن آب‌وهوای زنده برای **۹۹۴ شهر ایران**.

## امکانات
- انتخاب شهر با جستجوی فارسی (یا انگلیسی) + فیلتر استان
- وضعیت لحظه‌ای: دما، دمای احساسی، رطوبت، نقطه شبنم، فشار، باد، ابر، پدیده
- پیش‌بینی **ساعت‌به‌ساعت تا ۷ روز آینده** (۱۶۸ ساعت)
- پیش‌بینی روزانه ۷ روز: بیشینه/کمینه، طلوع/غروب، UV، بارش، ماه
- نمونه‌نگاره (نمودار) تعاملی دما و بارش
- کش ۱۵ دقیقه‌ای + پاسخ stale در صورت قطعی سرویس بالادست

## اجرا
```bash
/usr/local/bin/python3 -m uvicorn app.server:app --host 127.0.0.1 --port 8734
```

## ساختار
```
iran-weather/
├── app/server.py      # بک‌اند FastAPI
├── static/index.html  # فرانت‌اند (تک‌فایل، RTL)
└── data/cities.json   # ۹۹۴ شهر از GeoNames (فارسی+لاتین+استان)
```

## منبع داده
- شهرها: [GeoNames](https://www.geonames.org) (CC BY 4.0)
- آب‌وهوا: [Open-Meteo](https://open-meteo.com) (CC BY 4.0) — بدون نیاز به کلید API
