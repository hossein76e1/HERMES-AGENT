# 🍳 ربات آشپزی فوق پیشرفته تلگرام

ربات هوشمند و جامد آشپزی برای تلگرام با ده‌ها امکان حرفه‌ای: جستجوی دستور پخت، برنامه غذایی هفتگی، کالری‌شماری، تشخیص غذا از عکس با هوش مصنوعی، لیست خرید خودکار، سیستم امتیاز و سطح‌بندی و پشتیبانی کامل از عکس و ویدیو.

---

## ✨ امکانات ربات

| ویژگی | توضیح |
|---|---|
| 🔍 جستجوی دستور پخت | جستجو بر اساس **نام غذا** یا **مواد اولیه موجود** در خانه |
| 🍽️ دسته‌بندی غذاها | ایرانی، فست‌فود، کیک و شیرینی، سالاد، دسر، سوپ، صبحانه، گیاهی و... |
| 🛒 لیست خرید خودکار | ساخت خودکار لیست خرید از دستور پخت انتخابی + مدیریت آیتم‌ها |
| 📅 برنامه غذایی هفتگی | چیدمان برنامه غذایی ۷ روزه + یادآور پخت با جاب (`JobQueue`) |
| 🔥 کالری‌شماری | اطلاعات تغذیه‌ای کامل: کالری، پروتئین، چربی، کربوهیدرات |
| 💊 پیشنهاد بر اساس رژیم | رژیم لاغری، دیابت، گیاهی، پرورش اندام و بدون گلوتن |
| 🤖 تشخیص غذا از عکس | شناسایی غذا از روی عکس با هوش مصنوعی (Vision API) |
| ⭐ علاقه‌مندی‌ها | ذخیره دستورهای محبوب و دسترسی سریع |
| 🏆 امتیاز و سطح‌بندی | کسب امتیاز با تعامل، نوار سطح (کوک‌آموز تا سرآشپز طلایی) |
| 📸 عکس و ویدیو | نمایش عکس غذا و ویدیوی آموزشی دستور پخت |

---

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Python **3.10+**
- یک توکن ربات از [@BotFather](https://t.me/BotFather)
- (اختیاری) کلید API سرویس تشخیص تصویر برای قابلیت شناسایی غذا از عکس

### مراحل اجرا

```bash
# ۱. کلون یا دانلود پروژه
cd cooking-bot

# ۲. ساخت محیط مجازی
python -m venv venv
source venv/bin/activate        # لینوکس/مک
venv\Scripts\activate           # ویندوز

# ۳. نصب وابستگی‌ها
pip install -r requirements.txt

# ۴. تنظیم متغیرهای محیطی (بدون قرار دادن کلید در کد!)
export BOT_TOKEN="توکن_ربات_شما"
export VISION_API_KEY="کلید_سرویس_تشخیص_تصویر"   # اختیاری

# ۵. اجرا
python main.py
```

> ⚠️ **نکته امنیتی:** هرگز توکن ربات و کلیدهای API را داخل کد قرار ندهید. همیشه از متغیرهای محیطی یا فایل `.env` استفاده کنید.

### متغیرهای محیطی

| نام | الزامی | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ بله | توکن ربات دریافتی از BotFather |
| `VISION_API_KEY` | ❌ خیر | کلید سرویس تشخیص غذا از عکس (در نبود آن، این قابلیت پیام راهنما نشان می‌دهد) |
| `DATABASE_URL` | ❌ خیر | آدرس دیتابیس (پیش‌فرض: SQLite محلی `cooking_bot.db`) |

## 📋 دستورات ربات

```
/start        - شروع کار و منوی اصلی
/help         - راهنمای کامل استفاده
/recipes      - مشاهده دسته‌بندی دستور پخت‌ها
/search       - جستجوی غذا بر اساس نام
/ingredients  - جستجو بر اساس مواد موجود در خانه
/shopping     - لیست خرید من
/mealplan     - برنامه غذایی هفتگی
/calories     - کالری‌شماری و اطلاعات تغذیه‌ای
/diet         - تنظیم رژیم غذایی و دریافت پیشنهاد
/favorites    - دستورهای علاقه‌مندی من
/profile      - پروفایل، امتیاز و سطح کاربر
/settings     - تنظیمات و یادآور پخت
```

### 💡 قابلیت تشخیص غذا از عکس
کافیست **عکس غذا را مستقیماً برای ربات بفرستید** تا با هوش مصنوعی، نام غذا شناسایی و دستور پخت آن نمایش داده شود.

## 🏗️ ساختار پروژه

```
cooking-bot/
│
├── main.py              # نقطه ورود، راه‌اندازی ربات و ثبت هندلرها
├── requirements.txt     # وابستگی‌های پروژه
├── README.md            # همین مستندات
└── (دیتابیس SQLite به‌صورت خودکار ساخته می‌شود)
```

`main.py` به‌صورت ماژولار سازمان‌دهی شده و شامل موارد زیر است:

- **مدل‌های دیتابیس (SQLAlchemy):** کاربران، دستور پخت‌ها، مواد اولیه، علاقه‌مندی‌ها، لیست خرید، برنامه غذایی، امتیازها
- **هندلرها:** منوی اصلی، جستجو، دسته‌بندی، لیست خرید، برنامه غذایی، کالری، رژیم، علاقه‌مندی‌ها، آپلود عکس
- **JobQueue:** یادآورهای زمان‌بندی‌شده پخت و برنامه غذایی هفتگی
- **دیتای اولیه:** بیش از ۳۰ دستور پخت ایرانی و بین‌المللی با اطلاعات تغذیه‌ای به‌صورت خودکار در اولین اجرا ثبت می‌شود

## 🛠️ تکنولوژی‌ها

- **python-telegram-bot** — فریم‌ورک اصلی ربات (نسخه ۲۰+ با async/await)
- **SQLAlchemy** — ORM و مدیریت دیتابیس SQLite
- **httpx** — ارتباط با سرویس هوش مصنوعی تشخیص تصویر
- **APScheduler / JobQueue** — یادآورهای زمان‌بندی‌شده
