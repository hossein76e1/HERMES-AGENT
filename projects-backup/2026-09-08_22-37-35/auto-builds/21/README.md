# 🍳 ربات تلگرام دستور آشپزی

ربات تلگرامی پیشرفته و حرفه‌ای برای ارائه دستور پخت غذا که هر روز به‌صورت خودکار دستور پخت جدید برای کاربران ارسال می‌کند. این ربات با معماری غیرهمزمان (Async) طراحی شده و قابلیت سرویس‌دهی به **هزاران کاربر** به‌صورت همزمان را دارد.

---

## ✨ ویژگی‌ها

### 👤 امکانات کاربران
- 📅 **دستور پخت روز**: ارسال خودکار دستور پخت جدید هر روز در ساعت مشخص
- 🔍 **جستجوی هوشمند**: جستجوی دستور غذا بر اساس نام غذا **یا مواد اولیه موجود در آشپزخانه**
- 🗂 **دسته‌بندی غذاها**: شام، صبحانه، ناهار، دسر، پیش‌غذا، گیاهی (وِگان)، فست‌فود و غذای ایرانی
- ❤️ **علاقه‌مندی‌ها**: ذخیره دستورهای مورد علاقه و مرور آن‌ها در هر زمان
- 🖼 **ارسال عکس غذا**: هر دستور پخت همراه با عکس باکیفیت غذا ارسال می‌شود
- 🎲 **غذای تصادفی**: پیشنهاد ناگهانی یک دستور پخت برای روزهایی که انتخاب سخت است!
- 🔔 **فعال/غیرفعال کردن ارسال روزانه**: کاربر کنترل کامل روی دریافت دستور روز دارد

### 🛠 پنل مدیریت (Admin Panel)
- ➕ افزودن دستور پخت جدید (نام، دسته، مواد اولیه، مراحل، لینک عکس)
- ✏️ ویرایش و 🗑 حذف دستورهای پخت
- 📊 **آمار کامل**: تعداد کاربران، دستورها، کاربران فعال روزانه
- 📢 **پیام همگانی (Broadcast)**: ارسال پیام به هزاران کاربر با نرخ محدودشده برای جلوگیری از بلاک شدن
- 📋 مشاهده لیست دستورها با صفحه‌بندی (Pagination)

## 🏗 معماری و تکنولوژی

| بخش | تکنولوژی |
|---|---|
| زبان | Python 3.10+ |
| فریم‌ورک ربات | aiogram 3.x (کاملاً Async) |
| دیتابیس | SQLite با aiosqlite |
| زمان‌بند | APScheduler (ارسال خودکار روزانه) |
| کانفیگ | متغیرهای محیطی با python-dotenv |

### ساختار پروژه

```
.
├── main.py              # نقطه ورود: اجرای ربات + زمان‌بند + ساخت جداول
├── requirements.txt     # وابستگی‌های پروژه
├── README.md            # همین فایل
├── .env                 # تنظیمات محیطی (باید خودتان بسازید)
└── data/
    └── recipes.db       # دیتابیس SQLite (به‌صورت خودکار ساخته می‌شود)
```

## 🚀 راه‌اندازی

### ۱. دریافت توکن ربات
از [@BotFather](https://t.me/BotFather) در تلگرام یک ربات جدید بسازید و توکن آن را دریافت کنید.

### ۲. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی
فایلی با نام `.env` در کنار `main.py` بسازید:

```env
# توکن ربات (از BotFather)
BOT_TOKEN=123456:ABC-DEF_your_token_here

# آیدی عددی ادمین‌ها (از @userinfobot بگیرید) - چند ادمین با کاما جدا شوند
ADMIN_IDS=123456789,987654321

# زمان ارسال دستور روز (قالب HH:MM به وقت تهران)
DAILY_RECIPE_TIME=10:00

# منطقه زمانی
TIMEZONE=Asia/Tehran

# مسیر فایل دیتابیس (اختیاری)
DATABASE_PATH=data/recipes.db

# سطح لاگ (اختیاری)
LOG_LEVEL=INFO
```

> ⚠️ **نکته امنیتی**: هرگز توکن ربات را در کد یا گیت کامیت نکنید. همیشه از متغیرهای محیطی استفاده کنید.

### ۴. اجرا

```bash
python main.py
```

ربات بالا می‌آید، دیتابیس و جداول به‌صورت خودکار ساخته می‌شوند و دستورهای نمونه اولیه (Seed Data) در صورت خالی بودن دیتابیس اضافه می‌شوند.

## 📖 راهنمای استفاده

### دستورهای کاربران

| دستور | توضیح |
|---|---|
| `/start` | شروع ربات، ثبت‌نام و فعال‌سازی دستور روزانه |
| `/help` | راهنمای کامل ربات |
| `/today` | مشاهده دستور پخت امروز |
| `/random` 🎲 | یک دستور پخت تصادفی |
| `/search` | جستجو بر اساس نام یا مواد اولیه |
| `/categories` | مرور دسته‌بندی غذاها |
| `/favorites` | مشاهده دستورهای ذخیره‌شده |

همچنین از طریق منوی دکمه‌ای (Reply Keyboard) می‌توانید به همه امکانات دسترسی داشته باشید.

### دستورهای ادمین

| دستور | توضیح |
|---|---|
| `/admin` | ورود به پنل مدیریت |
| `/stats` | آمار سریع ربات |
| `/addrecipe` | افزودن دستور پخت جدید (فرم گام‌به‌گام) |
| `/broadcast` | ارسال پیام همگانی به همه کاربران |
| `/recipes` | لیست دستورها با امکان ویرایش/حذف |

## 🗄 دیتابیس

جداول اصلی:

- **users**: شناسه کاربر، نام، وضعیت دریافت روزانه، تاریخ عضویت
- **recipes**: نام، دسته، مواد اولیه، مراحل پخت، لینک عکس، تاریخ ثبت
- **favorites**: رابط کاربر-دستور (علاقه‌مندی‌ها)
- **daily_log**: ثبت دستور ارسالی هر روز (برای عدم تکرار)

فیلد `ingredients` به‌صورت متنی جستجو می‌شود؛ یعنی اگر کاربر بنویسد «مرغ برنج»، تمام دستورهایی که هر دو ماده را دارند اولویت نمایش پیدا می‌کنند.

## 📈 مقیاس‌پذیری برای هزاران کاربر

- معماری **کاملاً غیرهمزمان (asyncio)** برای پردازش همزمان درخواست‌ها
- **Broadcast با نرخ کنترل‌شده** (حدود ۲۰ پیام در ثانیه) و توقف خودکار در صورت محدودیت تلگرام
- ایندکس‌گذاری روی جداول برای جستجوی سریع
- اتصال Singleton به دیتابیس با WAL mode برای خواندن/نوشتن همزمان

برای میلیون‌ها کاربر می‌توانید دیتابیس را به PostgreSQL و وب‌هوک را روی سرور فعال کنید؛ ساختار کد این مهاجرت را ساده می‌کند.

## 🔧 رفع اشکال

| مشکل | راه‌حل |
|---|---|
| خطای `BOT_TOKEN not found` | فایل `.env` را در کنار `main.py` بسازید |
| ارسال روزانه انجام نمی‌شود | فرمت `DAILY_RECIPE_TIME` را بررسی کنید (مثال: `10:00`) و منطقه زمانی سرور را چک کنید |
| ادمین شناخته نمی‌شوید | `ADMIN_IDS` باید آیدی **عددی** باشد نه یوزرنیم |
| عکس‌ها نمایش داده نمی‌شوند | لینک عکس باید مستقیم (Direct Link) و با پسوند `.jpg`/`.png` باشد |
