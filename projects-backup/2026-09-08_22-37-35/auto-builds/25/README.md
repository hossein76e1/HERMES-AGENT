# 🍳 ربات آشپزی تلگرام

ربات فوق پیشرفته آشپزی تلگرام با امکانات کامل برای جستجوی دستور پخت، پیشنهاد غذا بر اساس مواد موجود، مدیریت لیست خرید هوشمند و محاسبه کالری و ارزش غذایی.

## ✨ امکانات

- 🔍 **جستجوی دستور پخت** — جستجوی غذا بر اساس نام یا بخشی از نام
- 🍽️ **دسته‌بندی غذاها** — مرور دستور پخت‌ها بر اساس دسته (صبحانه، ناهار، شام، دسر، پیش‌غذا و...)
- 🥕 **پیشنهاد غذا بر اساس مواد موجود** — مواد داخل یخچالتان را وارد کنید تا غذاهای قابل تهیه به شما پیشنهاد شود
- ❤️ **ذخیره علاقه‌مندی‌ها** — ذخیره دستور پخت‌های محبوب برای دسترسی سریع
- 🛒 **لیست خرید هوشمند** — افزودن مواد غذایی به لیست خرید، علامت‌زدن به عنوان خریده‌شده و پاک‌سازی لیست
- 🔥 **محاسبه کالری و ارزش غذایی** — نمایش کالری، پروتئین، کربوهیدرات و چربی هر غذا
- ⏰ **تایمر و یادآور پخت** — تنظیم تایمر پخت با یادآوری خودکار در تلگرام
- 🥗 **پشتیبانی از رژیم‌های خاص** — فیلتر دستور پخت‌ها بر اساس رژیم (گیاهی، وگان، کتوژنیک، بدون گلوتن، رژیمی)
- 🎲 **دستور پخت تصادفی روزانه** — پیشنهاد غذای تصادفی برای تنوع در پخت‌وپز

## 🛠️ تکنولوژی‌ها

- **Python 3.10+**
- **python-telegram-bot v21** (کاملاً async)
- **SQLite** — ذخیره‌سازی داده‌های کاربران بدون نیاز به سرور جداگانه
- **APScheduler** — مدیریت تایمرها و یادآورهای پخت

## 📦 نصب

۱. پروژه را دانلود یا کلون کنید:

```bash
git clone <آدرس-پروژه>
cd telegram-cooking-bot
```

۲. محیط مجازی بسازید و فعال کنید:

```bash
python -m venv venv
source venv/bin/activate   # لینوکس / مک
venv\Scripts\activate      # ویندوز
```

۳. وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

## ⚙️ تنظیمات

توکن ربات را از [@BotFather](https://t.me/BotFather) دریافت کرده و به صورت **متغیر محیطی** تنظیم کنید (توکن هرگز در کد ذخیره نمی‌شود):

```bash
# لینوکس / مک
export BOT_TOKEN="123456:ABC-DEF_your_token_here"

# ویندوز (PowerShell)
$env:BOT_TOKEN="123456:ABC-DEF_your_token_here"

# ویندوز (CMD)
set BOT_TOKEN=123456:ABC-DEF_your_token_here
```

### متغیرهای محیطی

| متغیر | توضیح | پیش‌فرض |
|-------|-------|---------|
| `BOT_TOKEN` | توکن ربات تلگرام (**الزامی**) | — |
| `DB_PATH` | مسیر فایل دیتابیس SQLite | `cooking_bot.db` |

## 🚀 اجرا

```bash
python main.py
```

پس از اجرا، ربات در حالت Long-Polling شروع به کار می‌کند و پیام «ربات آشپزی فعال شد» در کنسول نمایش داده می‌شود.

## 🤖 دستورات ربات

| دستور | توضیح |
|-------|-------|
| `/start` | شروع کار و نمایش منوی اصلی |
| `/help` | راهنمای کامل استفاده از ربات |
| `/search` | جستجوی دستور پخت بر اساس نام |
| `/categories` | مشاهده دسته‌بندی غذاها |
| `/ingredients` | پیشنهاد غذا بر اساس مواد موجود |
| `/favorites` | مشاهده و مدیریت علاقه‌مندی‌ها |
| `/shopping` | مشاهده و مدیریت لیست خرید |
| `/random` | دستور پخت تصادفی |
| `/diet` | تنظیم رژیم غذایی خاص |
| `/timer` | تنظیم تایمر و یادآور پخت |
| `/stats` | آمار شخصی (تعداد علاقه‌مندی‌ها و...) |

## 🗄️ دیتابیس

ربات از SQLite استفاده می‌کند و در اولین اجرا جداول زیر را به صورت خودکار ایجاد می‌کند:

| جدول | توضیح |
|------|-------|
| `users` | اطلاعات کاربران و رژیم غذایی انتخابی |
| `recipes` | دستور پخت‌ها شامل مواد، مراحل، کالری و ارزش غذایی |
| `favorites` | دستور پخت‌های مورد علاقه هر کاربر |
| `shopping_list` | اقلام لیست خرید کاربران |

## 📝 نکات مهم

- تمام داده‌های کاربران به صورت **محلی** در فایل دیتابیس ذخیره می‌شوند و هیچ داده‌ای به سرور دیگری ارسال نمی‌شود.
- توکن ربات فقط از متغیر محیطی `BOT_TOKEN` خوانده می‌شود؛ در صورت تنظیم نکردن آن، ربات با پیام خطای واضح متوقف می‌شود.
- برای توقف ربات کلیدهای `Ctrl+C` را فشار دهید؛ ربات به صورت تمیز خاموش می‌شود و تایمرهای فعال ذخیره می‌شوند.
- دستور پخت‌های نمونه در اولین اجرا به صورت خودکار در دیتابیس قرار می‌گیرند تا بلافاصله بتوانید از ربات استفاده کنید.
