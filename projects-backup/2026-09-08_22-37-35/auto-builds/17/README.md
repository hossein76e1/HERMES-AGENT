# 🤖 ربات لایک اینستاگرام (تلگرام)

ربات ساده تلگرامی برای لایک کردن پست‌های اینستاگرام از طریق دریافت لینک پست.

## ✨ ویژگی‌ها
- دریافت لینک پست اینستاگرام و ارسال لایک خودکار
- خواندن اطلاعات اکانت اینستاگرام از متغیرهای محیطی (بدون هاردکد کردن رمز)
- پیام‌های فارسی و راهنمای کاربری داخل ربات
- جلوگیری از لایک تکراری برای یک پست در هر جلسه
- کنترل ساده نرخ لایک برای کاهش ریسک محدودیت

## 📋 پیش‌نیازها
- Python 3.9 یا بالاتر
- توکن ربات تلگرام (از [@BotFather](https://t.me/BotFather) دریافت کنید)
- یک اکانت اینستاگرام (ترجیحاً اکانت تست، نه اکانت اصلی)

## ⚙️ نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

## 🔑 متغیرهای محیطی

قبل از اجرا، متغیرهای زیر را تنظیم کنید (هیچ کلید یا رمزی در کد ذخیره نشده است):

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات تلگرام از BotFather |
| `IG_USERNAME` | نام کاربری اکانت اینستاگرام لایک‌کننده |
| `IG_PASSWORD` | رمز عبور همان اکانت |

مثال در لینوکس:

```bash
export BOT_TOKEN='123456:ABC-DEF...'
export IG_USERNAME='my_account'
export IG_PASSWORD='my_password'
```

مثال در ویندوز (PowerShell):

```powershell
$env:BOT_TOKEN='123456:ABC-DEF...'
$env:IG_USERNAME='my_account'
$env:IG_PASSWORD='my_password'
```

## 🚀 اجرا

```bash
python main.py
```

## 📱 نحوه استفاده از ربات

1. ربات را در تلگرام استارت کنید: `/start`
2. لینک پست اینستاگرام را ارسال کنید، مثلاً:
   `https://www.instagram.com/p/XXXXXXXX/`
3. ربات پست را بررسی و لایک می‌کند و نتیجه را به فارسی اعلام می‌کند.

دستورات ربات:
- `/start` — شروع و نمایش راهنما
- `/help` — راهنمای استفاده
- `/like <لینک>` — لایک کردن مستقیم یک پست

## ⚠️ نکات مهم
- این ربات از API غیررسمی اینستاگرام استفاده می‌کند؛ لایک بیش از حد ممکن است باعث محدودیت موقت یا مسدود شدن اکانت اینستاگرام شود.
- حتماً از اکانت تست استفاده کنید و فاصله بین لایک‌ها را رعایت کنید.
- مسئولیت استفاده از ربات کاملاً بر عهده کاربر است.
- توکن‌ها و رمزها فقط از متغیرهای محیطی خوانده می‌شوند و در هیچ‌جای کد ذخیره نمی‌شوند.
